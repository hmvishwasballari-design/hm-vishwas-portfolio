# Vishwas Nexus Portfolio

A premium, animated Vite + React portfolio for H M Vishwas, including a dedicated personal introduction section.

## Projects shown

Only the six public repositories currently visible on the GitHub profile are represented:

1. AI-Pentest-Framework
2. AI_IDS
3. enterprise-rag-dashboard
4. smart-data-cleaner
5. smart-data-cleaner-webapp
6. razorguard-ai

No VAI project and no duplicated project section are included.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Notes

- The visual direction is inspired by modern editorial/product launch pages, not a copy of any specific website.
- GitHub repository links point to H M Vishwas's public GitHub repositories.
- Contact links are included for email, GitHub and LinkedIn.
